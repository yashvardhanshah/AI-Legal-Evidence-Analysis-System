# Development rules

Work sequentially through IMPLEMENTATION_PLAN.md. Stop after each phase for review.
Ask the user before every commit or push. Never force push or delete remote content.
Never commit secrets, evidence, datasets, models or runtime database files.
No fabricated legal material, evidence, statistics, model results or test claims.
Run appropriate tests and record actual outcomes in TESTING.md.
Keep services local until authentication and case-level authorization are implemented.
Dataset downloads require provenance and license review; large downloads and paid usage require approval.
