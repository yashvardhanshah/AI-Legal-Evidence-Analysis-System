# Model and processing register

Phase 7 performs no new model inference or download. Deterministic report summaries count and attribute actual snapshot records. Existing OCR/NLP/YOLOX/MiniLM versions and hashes are retained in the private report appendix; an AI output remains an unverified observation, not a finding. Optional external LLM summarization is not implemented or enabled. Verified statutory recommendations remain unavailable.

Phase 6 reuses the installed pinned MiniLM and its 91,578,415-byte eleven-file snapshot; no model, dependency or paid API is acquired. `extractive-research-v1` creates exact 220-word-piece query windows with 32 overlap, capped at sixteen windows/job, and retains per-file hashes/software in the model registry and private run provenance. Source distances are cosine distances, not legal accuracy/applicability probabilities. No Gemini or other LLM integration is configured; private evidence never leaves the local stack. Automatic NLP/vision observations are excluded from factual inputs. Statute indexing uses a separate collection/directory and remains data-gated pending verified official rights and version metadata.

Phase 5 adds Apache-2.0 OpenCV Zoo YOLOX-S ONNX (35,858,002 bytes), pinned official mirror revision `d4938dfc9d4ec5d098bfa33e98b3f3345a236586`, verified SHA-256 `c5c2d13e59ae883e6af3b45daea64af4833a4951c92d116ec270d9ddbe998063`. Real local OpenCV DNN emits only supported COCO object candidates; class indices are contiguous 0–79, scores are uncalibrated objectness × class probability, and video results are sampled frames rather than tracking. Model/source/wheel licenses, exact acquisition sizes, provenance and limitations: [PHASE5_REPORT.md](docs/PHASE5_REPORT.md). Earlier models remain unchanged.

Phase 4 adds a separately approved 261,694,557-byte Apache-2.0 DistilBERT NER snapshot, versioned deterministic mention rules and real Tesseract TSV provenance. Exact revisions, hashes, licenses, byte sizes and score semantics are documented in [PHASE4_DESIGN.md](docs/PHASE4_DESIGN.md). The Phase 2 encoder and Chroma collection below are unchanged.

Encoder: [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), Apache-2.0, pinned commit `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. The [pinned model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/blob/1110a243fdf4706b3f48f1d95db1a4f5529b4d41/README.md) describes English sentence/short-paragraph encoding into 384 dimensions and a 256-word-piece context. It is general-purpose and has not been evaluated for Indian legal relevance here.

The approved eleven-file safetensors/tokenizer snapshot is **91,578,415 bytes** in ignored `.local/phase2/models/<revision>/`, mounted at `/private_data/models/<revision>/`. Its manifest records revision, retrieval time, bytes and per-file SHA-256; safetensors is also checked against publisher LFS SHA-256. Runtime verifies local integrity, sets `local_files_only=True`, disables remote custom code and uses CPU inference with two Torch threads. Downloads happen only through an explicit budgeted operator command. No paid API or GPU is used.

Verified Linux CPU environment: Torch **2.9.1+cpu**, Sentence Transformers **5.7.0**, Transformers **4.57.6**, Chroma **1.5.9**, pypdf **6.21.1**, pypdfium2 **5.14.0** and Tesseract **5.5.0**. The 115-package snapshot is in `backend/requirements-ml.lock`. The Dockerfile bootstraps the CPU environment then reconciles that exact lock and runs `pip check`; this preserves the already-built large dependency cache. A real stored passage produced a normalized **1 × 384** embedding during preflight. This confirms execution, not retrieval quality.

Chunks use the pinned fast tokenizer: 220 word pieces, 32-token overlap, one page per chunk. Context including special tokens is checked, never silently truncated. Search queries beyond 256 tokens are rejected. Page-normalization hashes and passage character offsets make extraction reproducible; originals remain unchanged.

Chroma's persistent local cosine-distance collection is `judgment_passages_minilm_v1`, with model/revision metadata and telemetry disabled. Explicit embeddings bypass Chroma's default downloadable model. Passage UUIDs are deterministic vector IDs, with judgment and text-hash references. Search results require matching committed SQL passages and model/hash provenance; orphaned vectors are suppressed. Deterministic upserts and a PostgreSQL writer lock support safe retries.

Embedded PDF text uses [pypdf, BSD licensed](https://github.com/py-pdf/pypdf/blob/main/LICENSE), avoiding the additional PyMuPDF copyleft/commercial licensing decision in this phase. Blank scanned pages with image resources use local Tesseract English OCR via pypdfium2 only when required. Page and OCR timeout limits are enforced. OCR fallback is tested on a rasterized derivative of a real acquired source page. No OCR accuracy claim is made.

Distances are measured model outputs, not legal confidence or applicability. No recall, ranking accuracy or evaluation score is claimed. Historical English sampling and publisher metadata limit generalization. No LLM, vision detector, facial matching or guilt model is enabled.
