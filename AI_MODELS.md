# AI model register

No model is installed, downloaded, invoked or evaluated in Phase 1. No accuracy or inference claims are made.

Future candidates: Tesseract/EasyOCR for scanned pages; PyMuPDF for embedded text; spaCy/Transformers for extraction; Sentence Transformers with persistent Chroma for retrieval; YOLO only after model/code/data license review; configurable Gemini or a feasible local model for source-grounded summaries. Record exact artifact/version, source, license, checksum, supported labels, hardware requirements and measured evaluation before enabling any model. Paid APIs and large downloads require approval.

Model confidence must never be interpreted as criminal culpability. No facial identity matching or automated guilt determination is in scope. Treat evidence text as untrusted data and retain evidence/page/passage references for human review.
